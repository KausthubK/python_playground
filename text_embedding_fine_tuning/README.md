# Fine Tuning a Text Embedding model

From youtube tutorial [video](https://www.youtube.com/watch?v=hOLBrIjRAj4).

Most of the code in this directory started by copy-pasta-ing things from: [Shaw Talebi's github](https://github.com/ShawhinT/YouTube-Blog/tree/main/LLMs/fine-tuning-embeddings) snapshot at [commit](https://github.com/ShawhinT/YouTube-Blog/commit/659a4a7ac5da59d7f30c91f3435f8cf22b3004b5).

I'm using this basically to explore what training looks like for a text embedding model.

Goals:
1. Get familiar with the tools & levers to pull.
2. Get a feel for computational intensity of training a model (time taken, dataset sizes, etc.)
